# Логистическая регрессия с регуляризацией

Классификация микрочипов по результатам двух тестов.

Реализованы с нуля на NumPy:

- полиномиальные признаки до шестой степени;
- логистическая регрессия и градиентный спуск;
- L1- и L2-регуляризация;
- комбинация L1 и L2 (Elastic Net);
- визуализация границы решений;
- сравнение переобучения, нормального обучения и недообучения;
- предсказание класса и вероятности для нового объекта.

Запуск:

```bash
python ex1.py
```
